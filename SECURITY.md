# Security policy

Report vulnerabilities through GitHub's private vulnerability reporting feature. Include the affected commit, policy/request pair, expected and observed decision, impact, and a minimal reproduction. Never include production credentials, real audit keys, customer data, or live payment identifiers.

Only the latest release line receives fixes. The example server lacks caller authentication and must not be exposed to an untrusted network. Review the [threat model](docs/threat-model.md) and [audit design](docs/audit-ledger.md) before deployment.
